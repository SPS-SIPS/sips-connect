# Security Policy

## Reporting Vulnerabilities

Please do not report security vulnerabilities through public GitHub issues.

Report suspected vulnerabilities privately to the institutional maintainers of
SOMALI PAYMENT SWITCH (SPS) LTD through the approved SPS security-reporting
channel.

Include, where possible:

- Affected component or endpoint.
- Impact summary.
- Reproduction steps.
- Relevant logs or request identifiers with sensitive values removed.
- Suggested mitigation, if known.

## Sensitive Material

Do not commit credentials, private keys, certificates with private material,
production configuration, participant secrets, production transaction data, or
vendor-proprietary SmartVista material.

If sensitive material is committed, rotate the affected credential first, then
coordinate repository history cleanup with the institutional maintainers.
