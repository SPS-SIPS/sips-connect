# SIPS EMV QR Standard

This package provides a Emv SomQR Standard Support For SIPS.

## Overview

The SIPS EMV SomQR Standard package provides functionality to generate SomQR codes that comply with the EMV SomQR standard. The package includes the following features:

- **SomQR Person QR**: Generates a SomQR code for a person.
- **SomQR Merchant QR**: Generates a SomQR code for a merchant.

## Installation

To install the package, follow these steps:

1. Add the package to your project.

```bash
dotnet add package SIPS.Emv
```
